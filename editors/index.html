        Publishing a weekly note
        
          
          
            
        1. Open the Weekly note tab and paste the desk's finished note into the boxes. The checks underneath the form turn green when the note meets the rules.
          2. 
            
        2. Copy file, then click Open GitHub → new file. Sign in if asked.
          3. 
            
        3. In the Name your file box at the top, paste the file name shown under “1 · The file name”.
          4. 
            
        4. Click in the big empty box and paste the file contents.
          5. 
            
        5. Click the green Commit changes button, then Commit changes again in the pop-up.
          6. 
            
        6. Wait one to two minutes, then refresh the sector page. The note is live. If it is not there after five minutes, see the troubleshooting section of the Website Manual.
          7. 
            
        7. If the desk listed glossary terms, copy the glossary lines, click Open glossary.yml, click the pencil, paste the lines at the very bottom, and commit.
          8. 
          
        
        
        
        
        
          
        Rules the tool checks
        
          
          
            
        • One equity from the desk's coverage list.
          • 
            
        • Headline is 12 words or fewer and states the point.
          • 
            
        • 250–400 words across the four paragraphs.
          • 
            
        • At least one source, every source has a link.
          • 
            
        • No advice language: buy, sell, cheap, expensive, undervalued, overvalued, price target, I would invest.
          • 
            
        • Week is a Monday.
          • 
          
        
          
        Publishing later
        
          
        To stage a note on Sunday evening without it going live, change published: true to published: false before committing. On Monday morning open the file, click the pencil, change it back to true and commit. The note appears within two minutes.
