# Meridian62 — website

This folder is the complete Meridian62 website. It is built with Jekyll and hosted for free on GitHub Pages.
Read **Meridian62 — Launch & Website Manual.docx** for step-by-step instructions. In short:

| I want to…                                   | Edit this                                   |
|----------------------------------------------|---------------------------------------------|
| Add a weekly note                            | Create a file in `_notes/` (use the Editors' tools page at `/editors/`) |
| Change a desk's analysts or equities         | The desk's file in `_sectors/`              |
| Add a glossary term                          | `_data/glossary.yml`                        |
| Change who publishes when                    | `_data/schedule.yml`                        |
| Change editors, recap team, outreach, legal  | `_data/team.yml`                            |
| Change the site name, tagline, email, socials| `_config.yml`                               |
| Add a quarterly recap                        | Create a file in `_recaps/`                 |
| Change the About / Join / Legal text         | `about.html`, `join.html`, `legal.md`       |
| Add a sector cover image                     | Upload a square JPG to `assets/img/sectors/` and set `image:` in the sector file |

Nothing else needs touching.
